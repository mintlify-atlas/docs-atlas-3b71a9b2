Crossterm is a pure-Rust terminal manipulation library that makes it possible to write cross-platform text-based interfaces from a single codebase. It provides a unified API for controlling the cursor, applying styled output, reading keyboard and mouse events, and managing terminal state — all without reaching for platform-specific code. Crossterm targets every UNIX terminal and every Windows terminal down to Windows 7, and is designed to be safe to share across threads (`Send + Sync`), making it a solid foundation for TUI applications, interactive CLIs, and terminal games alike.

## Features

Crossterm is organized into focused modules, each covering a distinct area of terminal control.

**Cursor**
- Move the cursor N times in any direction (up, down, left, right)
- Move to previous / next line, or directly to a column or row
- Save and restore the cursor position
- Show or hide the cursor
- Enable or disable cursor blinking
- Set the cursor style (beam, underline, block, etc.)

**Styled Output**
- Set foreground and background colors using 16 base colors, 256 ANSI colors, or full RGB (Windows 10 and UNIX only)
- Apply text attributes: bold, italic, underline, crossed-out, dim, and more
- Render hyperlinks via `StartHyperlink` / `EndHyperlink`
- Respects the `NO_COLOR` environment variable

**Events**
- Keyboard input events with advanced modifier support (Shift, Alt, Ctrl)
- Mouse events: press, release, drag, position, and scroll (including scroll left/right)
- Terminal resize events
- Bracketed paste events
- Optional `futures::Stream` of events via the `event-stream` feature
- Poll/read API for both blocking and non-blocking use

**Terminal**
- Clear the screen (all lines, current line, from cursor up/down)
- Scroll up and down
- Get and set the terminal size
- Enter and leave the alternate screen
- Enable and disable raw mode
- Enable and disable line wrapping
- Set the terminal title

**Clipboard** *(optional, requires `osc52` feature)*
- Copy content to the system clipboard using OSC 52 sequences via `CopyToClipboard`

## Platform Support

Crossterm works on all platforms that support UNIX terminal semantics, as well as Windows 7 and later. On Linux and Windows 10, terminal commands are issued as ANSI escape codes written directly to the output stream. On older Windows systems, crossterm falls back to native WinAPI calls where ANSI codes are unavailable, so your application behaves correctly without any conditional logic in your own code.

## Thread Safety

All crossterm types are `Send + Sync`. You can share terminal handles across threads and drive output from worker threads without wrapping in additional synchronization primitives, which is essential for responsive TUI applications that separate rendering from input handling.
