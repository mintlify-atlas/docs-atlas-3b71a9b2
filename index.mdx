Crossterm is a pure-Rust, terminal manipulation library that makes it possible to write cross-platform text-based interfaces. It supports all UNIX terminals and Windows terminals down to Windows 7, with a clean and ergonomic Command API that gives you full control over when and how output is flushed.

## Get Started

<Steps>
  <Step title="Add crossterm to your project">
    Add the dependency to your `Cargo.toml`:
    ```toml Cargo.toml
    [dependencies]
    crossterm = "0.29"
    ```
  </Step>
  <Step title="Import and use the Command API">
    Use `execute!` to run terminal commands directly, or `queue!` to batch them:
    ```rust main.rs
    use std::io::{stdout, Write};
    use crossterm::{execute, style::{Color, Print, ResetColor, SetForegroundColor}};

    fn main() -> std::io::Result<()> {
        execute!(
            stdout(),
            SetForegroundColor(Color::Blue),
            Print("Hello from crossterm!\n"),
            ResetColor
        )
    }
    ```
  </Step>
  <Step title="Enable raw mode for interactive apps">
    Enable raw mode to capture keystrokes and build interactive programs:
    ```rust
    use crossterm::terminal::{enable_raw_mode, disable_raw_mode};
    use crossterm::event::{read, Event, KeyCode};

    fn main() -> std::io::Result<()> {
        enable_raw_mode()?;
        loop {
            if let Event::Key(key) = read()? {
                if key.code == KeyCode::Char('q') { break; }
            }
        }
        disable_raw_mode()
    }
    ```
  </Step>
  <Step title="Explore the guides">
    Dive deeper into each module — cursor, styling, events, terminal management, and more.
  </Step>
</Steps>

## Key Features

- **Cross-platform** — Works on all UNIX systems and Windows 7+, including Windows Terminal and Console Host
- **Zero-cost batching** — Use `queue!` to batch commands and flush only when ready, eliminating unnecessary I/O
- **Full event system** — Keyboard, mouse, focus, resize, and bracketed paste events with Kitty keyboard protocol support
- **Rich styling** — 16 base colors, 256-color ANSI, true RGB, and text attributes (bold, italic, underline, etc.)
- **Alternate screen** — Switch between the main and alternate terminal buffers like Vim does
- **Async-ready** — Optional `EventStream` for integrating with Tokio or smol async runtimes
- **Minimal dependencies** — Few carefully chosen dependencies, with optional features behind feature flags
